# Референсные реализации движка

Планируемая структура (Этап 1 плана):

```
engines/
  ts/       npm-пакет @lawlabs/marital-property — типы из схемы, движок SPEC § 4, тесты на vectors/
  swift/    SwiftPM-пакет DivorceCore — модель Codable, движок, XCTest на тех же vectors/
```

Требования к обеим реализациям:

- чистые функции без ввода‑вывода и без зависимостей от UI;
- проходят все векторы из `../vectors/` с допуском 0,01 ₽;
- при неизвестных значениях перечислений не падают, а выдают предупреждение;
- ставки пошлины и пороги подсудности датированы и хранятся таблицами, не константами в коде.

Приложения (LawMatic Divorce, Legalic) подключают пакеты как зависимости и не держат собственных копий формул.
