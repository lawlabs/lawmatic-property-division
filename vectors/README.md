# Тест-векторы

Один файл — один вектор. Формат описан в [`../schema/vector.schema.json`](../schema/vector.schema.json), правила — в [`../SPEC.md`](../SPEC.md) § 6.

| Категория | Что проверяет | Файлов |
|---|---|---|
| `division/` | состав массы, доли, долги, компенсация, цена иска, предупреждения | 7 |
| `fee/` | госпошлина по шкале ст. 333.19 НК РФ, соединение требований, жалобы | 12 |
| `jurisdiction/` | мировой судья / районный суд | 2 |
| `deadlines/` | исковая давность и годичный срок по сделке | 1 |
| `claim_price/` | отдельная категория; пока цена иска вшита в `division/*` | — |
| `warnings/` | отдельная категория; пока коды в `expected.warnings` векторов раздела | — |
| `roundtrip/` | экспорт → импорт | — |

Все векторы в статусе `draft`. Перевод в `confirmed` — отдельным коммитом с указанием, кем и чем проверено (`source_note`).

Обезличенные мотивы реальных дел: `llc-share-and-fx-debt` (доля в ООО и валютный долг), `dual-valuation-sold-car` (отчуждённый автомобиль, две оценки).
