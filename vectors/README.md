# Тест‑векторы

Один файл — один вектор. Формат описан в [`../schema/vector.schema.json`](../schema/vector.schema.json), правила — в [`../SPEC.md`](../SPEC.md) § 6.

| Категория | Что проверяет | Статус |
|---|---|---|
| `division/` | состав массы, идеальные доли, распределение активов и долгов, компенсация | 2 вектора, `draft` |
| `fee/` | госпошлина по шкале ст. 333.19 НК РФ (ред. 259‑ФЗ), соединение требований, фиксированная пошлина, обеспечение иска | 10 векторов, `draft` |
| `claim_price/` | цена иска по ст. 91 ГПК РФ | — |
| `deadlines/` | исковая давность, годичные сроки, апелляция/кассация | — |
| `jurisdiction/` | мировой судья / районный суд | — |
| `warnings/` | обязательные предупреждения движка | — |
| `roundtrip/` | экспорт → импорт → идентичный документ | — |

Перевод вектора из `draft` в `confirmed` — отдельным коммитом с указанием, кем и чем проверено (`source_note`).

Планируемые векторы из реальных дел (после обезличивания): ипотека с созаёмщиками и компенсацией; доли в ООО с уставным ограничением; долг в иностранной валюте; маткапитал в ипотечной квартире; отчуждённый автомобиль с оценкой стороны против судебной; встречный иск с отступлением от равенства долей.
